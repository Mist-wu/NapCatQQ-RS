# E2E 测试计划

## 目标

- 对接真实 QQ 账号与真实设备/网络链路。
- 覆盖私聊、群聊、图片、文件、撤回、群管理关键链路。
- 验证事件全链路 `QQ -> Protocol -> Event -> API -> Plugin`。

## 运行前提

1. 服务器上已部署可运行 QQ 协议网关。
2. 环境变量与凭据注入完成（登录态/代理/证书）。
3. 已启动 `napcat-rs` API 与协议服务。

## 测试清单

### 1. 登录与就绪

- [ ] 启动服务后返回运行态。
- [ ] `get_status` 与 `get_login_info` 与真实状态一致。

### 2. 私聊

- [ ] 发送文本消息并确认服务端收到 `message` 事件。
- [ ] 使用 API 回执验证 `send_private_msg` 发送成功。

### 3. 群聊

- [ ] 使用 `send_group_msg` 发布文本、图片、文件。
- [ ] 核对群事件中的 `message_id` 与群成员匹配。

### 4. 撤回与状态变更

- [ ] 验证消息撤回事件（`delete_msg` 或兼容回调）是否可触发。
- [ ] 验证重复撤回与不存在消息的失败响应。

### 5. 群管理与用户管理

- [ ] 群成员查询与基础成员信息拉取。
- [ ] 好友列表/API 群列表一致性。

## 结果格式

每次联调完成后，记录以下内容：

- 版本号与时间。
- 协议端点。
- 用例通过率。
- 失败截图与日志路径。
- 需要回归的缺陷与修复单。
