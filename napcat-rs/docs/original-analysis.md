# NapCat 原项目分析（初稿）

> 本文件记录 NapCatQQ 的关键实现方向，作为 Rust 重写的对齐基线。

## 关键子系统

- `core`：Runtime 生命周期、服务编排、任务调度。
- `protocol`：QQ 连接与消息解析（待替换为真实连接器）。
- `message`：统一消息模型（文本、图片、文件、At、回复、JSON）。
- `api`：HTTP/WebSocket 兼容 OneBot 11。
- `plugin`：插件系统（Rust/WASM/HTTP）。
- `storage`：持久化与缓存。

## 设计差异记录

1. Rust 侧重最小闭环：先统一关键抽象与可测边界，再逐步替换 mock 为真实实现。
2. 当前优先级：
   - 事件总线和协议/API 交互统一。
   - 插件生命周期与外部事件接入。
   - 真实登录与包收发接管测试闭环。
